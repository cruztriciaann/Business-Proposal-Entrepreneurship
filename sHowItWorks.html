How It Works
Arrive at the Event
Make sure you are physically inside the venue
Wait for the Organizer to Open Check-in
They will announce a 4-digit code verbally
Enter the Code in Check-in Tab
You have 5 minutes from when the code is given
Stay for the Event
GPS confirms you are near the venue
Check Out When Event Ends
Organizer gives another code — enter it in Check-out tab
Important: Do NOT share the code with anyone outside the venue. The system checks your GPS location to verify you are physically present.
